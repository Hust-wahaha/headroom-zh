# headroom-zh Windows 本地开发依赖清单（[all] 范围，kompress_zh 可用 + 代理评测）
#
# 用途：Windows 本地把 headroom-zh 的 kompress_zh 中文压缩通道真正跑起来。
# 不替代上游 pyproject.toml；AutoDL 上仍走 `uv pip install -e ".[all]"`（Linux 有 cargo，
# 可正常 maturin 构建 Rust core）。
#
# 关键修复（对应本机踩过的坑，详见 eval_docs/Windows部署修复记录.md）：
#   1. 必须用【非 Anaconda】的干净 Python 建 venv，否则 torch c10.dll 初始化失败(WinError 1114)。
#      根因：Anaconda 注入的 MKL / Intel-OpenMP 与 torch 自带 libiomp5md.dll 冲突。
#      正确做法：uv venv --python cpython-3.12.13-windows-x86_64-none （与已验证的
#      lora-finetune-qwen 环境同款干净解释器）。
#   2. torch 用 cu128 的 Windows wheel（本机有 NVIDIA GPU）；cpu wheel 在非 ASCII(中文)路径下
#      也会 c10.dll 初始化失败。
#   3. ms-swift 4.1.3 的 Qwen 加载器隐式需要 torchvision / qwen-vl-utils / av —— AutoDL 上靠
#      传递依赖顺带装，Windows 必须显式加。
#   4. headroom 是 maturin/Rust 工程；本机无 cargo，无法重编译。靠源码内【预编译】的
#      headroom/_core.pyd + site-packages 里的 headroom_ai.pth 完成 editable 挂载（脚本完成），
#      不触发 maturin 构建。
#
# 安装方式（PowerShell；先退出可能默认激活的 base conda）：
#   conda deactivate
#   uv python install 3.12
#   uv venv --python cpython-3.12.13-windows-x86_64-none `
#     "F:\模式识别课设\my_code\headroom_zh_eval\headroom-zh\.venv"
#   uv pip install --python ...\.venv\Scripts\python.exe `
#     --index-strategy unsafe-best-match -r eval\requirements-windows.txt
#   # 然后把一行源码根路径写入 ...\.venv\Lib\site-packages\headroom_ai.pth
