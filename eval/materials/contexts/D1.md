# kompress_zh 集成笔记——压缩 API 接口层与路由器改动

本文档为中文化的集成交接笔记，记录 `kompress_zh` 集成进 `headroom-zh` 过程中，各类改动的保留理由、不应盲目沿用的做法、以及仍存在不确定性的事项。阅读时请区分这三类语义，不要混为一谈。

## 一、整体目标与定位

本次集成的目标是：在 `headroom-zh` 中增加一条中文纯文本压缩分支（`kompress_zh`），同时保留原有的英文 `Kompress` 路径。

**这不是对 Kompress 的全库替换。** 区分如下：
- 英文或非中文主导的纯文本：继续走原有 `Kompress` 路径。
- 中文主导的纯文本：路由到 `kompress_zh` 分支处理。
- 结构化内容（JSON / 代码 / 日志 / HTML）：保持现有 Headroom 路由，不被 `kompress_zh` 劫持。

## 二、应当保留的改动

### 2.1 压缩 API 接口层（compress.py）

在 `headroom/compress.py` 中，以下改动必须保留：

- `CompressConfig.kompress_zh_model` 字段：允许在运行时覆盖中文 adapter，而不干扰原有英文压缩器的配置。
- `kompress_zh_model` 透传至 `pipeline.apply(...)` 的调用链：确保配置能实际生效。

保留理由：这是运行时可配置的关键接口，如果去掉，中文 adapter 的路径就无法在不重启代理的情况下切换，降低了系统的灵活性。

### 2.2 路由器改动（content_router.py）

在 `headroom/transforms/content_router.py` 中，以下函数和属性必须保留：

- `_is_chinese_dominant_text(...)`：中文主导判定函数，是路由分叉的决策核心。
- `_get_kompress_zh(...)`：获取中文压缩器实例的入口函数。
- `_runtime_kompress_zh_model`：运行时模型路径属性。
- 中文感知的 `_try_ml_compressor(...)` 逻辑变更。
- `_estimate_text_tokens(...)` 及其调用点的替换改动。

保留理由：语言路由是整个集成的核心接缝。特别需要注意：中文压缩不能用旧的仅空白符 token 估算逻辑来判定是否符合压缩阈值——旧逻辑会导致有效的中文压缩结果被路由器阈值拒绝。因此，`_estimate_text_tokens` 的替换是有实际意义的修正，不是可选的优化。

## 三、不应盲目沿用的做法

### 3.1 暗示 Kompress 被整体替换的 README 措辞

不要以"kompress_zh 取代了原有文本压缩器"的方式描述本次集成。正确表述：Headroom 保留了原有英文/纯文本压缩器；`kompress_zh` 是新增的中文分支。如果 README 措辞让读者误以为 Kompress 已被整体替换，会导致对架构的误解，影响下游集成和测试的判断。

### 3.2 将实验性 smoke 脚本作为产品代码发布

以下类型的脚本是验证产物，不是用户面向的仓库资产，不应作为产品代码发布：
- 临时性远程上传脚本
- 一次性 smoke 测试套件
- AutoDL 专用验证辅助脚本（如 `scripts/smoke_autodl_headroom.py`）

这些脚本在集成验证阶段有价值，但不适合进入正式代码发布流程。

### 3.3 无关的遗留 ONNX 导出改动

不要将中文 `kompress_zh` 集成与无关的 legacy ONNX 导出脚本改动混在同一次提交中，除非有独立的充分理由保留它们。

## 四、仍存在不确定性的事项

### 4.1 本地 Windows 环境的 pytest 不可信

在本 Windows 开发机上运行完整 `pytest` 的结果**不可作为可信的质量门控**，原因是当前本地环境缺少 `headroom._core`（Rust 原生扩展）和 `tiktoken`。这意味着部分测试在本地无法运行，通过的测试也不能代表在目标部署环境（AutoDL Linux 机器）上的行为。这一限制不影响 AutoDL 上的实际运行，但对于"本地测试通过即可合并"的结论持保留态度。

### 4.2 Windows zip 打包产生的反斜杠警告

Windows 本地打包的 zip 文件在 AutoDL Linux 环境中用 `unzip` 解压时，会产生关于反斜杠路径分隔符的警告。对于当前的 smoke 验证流程，这个警告是无害的，不影响功能。但对于一个成熟的验证工具链而言，这不是理想状态，未来应当修复。
